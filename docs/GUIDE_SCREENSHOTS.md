# Setup guide screenshots

The written guide is `website/src/pages/setup.astro`. Its screenshots are PNGs in `website/public/setup/`.
A missing file shows a marked placeholder on the page and a warning in the build output.

Retake them when Google AI Studio or the ScreenPulse Settings window changes. When you do:
- Hide anything personal: profile picture, name, email, project IDs, billing account, amounts, card details.
- Never show a real key. Make a throw-away key for the pictures, blur it, and delete it afterwards.
- Check each button name on Google's live screens and update the written guide to match.
