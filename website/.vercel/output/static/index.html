What ScreenPulse does today

  • Reads the screen you point at

    Press the shortcut and ScreenPulse captures the display your pointer is on, pointer included, so the AI knows which part of the screen you mean.

  • Explanatory answers in Normal Mode

    Point at a paragraph, an error message, a chart, a form or a question and get a direct answer followed by the reasoning. Type a follow-up to ask about the same screenshot.

  • Letter-only answers in Focus Mode

    For multiple-choice questions Focus Mode returns just the letter, fast. Content that is not multiple choice gets one short sentence and is never turned into a letter.

  • A floating answer window

    A compact window that stays above full-screen apps and every desktop. Show it or hide it per mode; ⌃⌥⌘ 0 brings back the last answer either way.

  • Caps Lock light signal

    The Caps Lock light flickers while the AI thinks, then signals the result: counted blinks for a letter or a number, long lights for yes and no.

    Needs a keyboard whose Caps Lock light macOS can control.

  • Keyboard backlight signal

    On MacBooks with a backlit keyboard the backlight can play the same pattern, which is easier to catch at a glance.

    Uses a system interface Apple does not document. It can differ between MacBook models and macOS versions.

  • You choose the outputs

    Window, Caps Lock light and backlight are separate switches, remembered per mode. Set the blink speed, test every pattern from the menu bar, and your own light settings are restored after each signal.

  • Your own reference notes

    Drop Markdown files into the Knowledge folder and ScreenPulse hands them to the AI as background for every question.

  • At home on macOS

    A menu bar app with no Dock icon. Global shortcut, API key in the macOS Keychain, optional start at login, and a build for both Apple silicon and Intel.

Not available yet

RGB keyboard lighting. Colour signals on external RGB keyboards are being explored. MacBook keyboards have a single-colour backlight, so this is not part of ScreenPulse today.

How it works

Set-up takes a few minutes: add your Gemini API key and give ScreenPulse two macOS permissions. After that it is one shortcut.

  1. Point

    Move the pointer to what you want help with. No selecting, no copying.

  2. Press ⌃⌥⌘ Space

    ScreenPulse captures the display under the pointer and sends that one image to Gemini.

  3. Wait a moment

    The window shows which model is answering. If a light output is on, Caps Lock flickers while the model works.

  4. Hear back your way

    The answer appears in the window, plays on your keyboard lights, or both, depending on the outputs you chose for the mode you are in.

Free and open source.

ScreenPulse costs nothing and has no accounts. Download the installer, drag the app to Applications, and you are done. The code is open under the Apache License 2.0, so you can read it, build it and change it.

ScreenPulse

Download for Mac

macOS 13 Ventura or later. Apple silicon and Intel.

Download ScreenPulse.dmg
  1. Open ScreenPulse.dmg from your Downloads folder.
  2. Drag the ScreenPulse icon onto Applications.
  3. Open ScreenPulse from Applications or Launchpad.
  4. The first time, your Mac says it could not verify ScreenPulse. Click Done (or OK), not Move to Trash.
  5. Open System Settings, then Privacy & Security. Scroll down to Security and click Open Anyway next to the message about ScreenPulse. Confirm with your password or Touch ID, then click Open Anyway once more.
  6. Add your Gemini key. The setup guide shows how.

Why the warning? Apple only skips it for apps signed with a paid Apple Developer ID. ScreenPulse is a free spare-time project and is not signed yet. You only need to do this once.

Build it yourself instead

You need the Xcode Command Line Tools. An app you build yourself opens without a warning.

git clone https://github.com/ande060h-ui/ScreenPulse.git
cd ScreenPulse
./app/build.sh
open build/ScreenPulse.app

  • Your own Gemini key, stored in the macOS Keychain

Questions

Why does my Mac say it cannot check ScreenPulse?

Apple lets a Mac skip that warning only for apps that their developer has signed with a paid Apple Developer ID. ScreenPulse is a free spare-time project, so a build may not be signed. When the warning appears, click Done (or OK), not Move to Trash. Then open System Settings, then Privacy & Security, scroll down to Security and click Open Anyway next to the message about ScreenPulse. Confirm with your password or Touch ID. You only need to do this once. The source code is public, and you can build the app yourself instead.

Which Macs does ScreenPulse run on?

ScreenPulse needs macOS 13 Ventura or later and runs on both Apple silicon and Intel Macs. It is made for MacBooks. There is no Windows or Linux version and none is planned.

Which MacBook models support the light signals?

The Caps Lock signal works when macOS lets ScreenPulse control the Caps Lock light of your keyboard. The backlight signal needs a MacBook with a backlit keyboard and relies on a system interface Apple does not document, so it can behave differently between models and macOS versions. We are still testing across MacBook models and will publish a compatibility list before launch. The Settings window shows which lights ScreenPulse found on your Mac, and the answer window works on every supported Mac.

Does it support RGB keyboard lighting?

Not yet. MacBook keyboards have a single-colour backlight, so colour signals would need an external RGB keyboard and support from its maker. We are looking into it, and it is not part of ScreenPulse today.

What is the difference between Normal Mode and Focus Mode?

Normal Mode is a general screen assistant: it explains what you point at, in full sentences, in the answer window. Focus Mode is deliberately minimal: for a multiple-choice question it returns only the letter, and by default signals it on the keyboard lights. If the content is not multiple choice, Focus Mode gives one short sentence and does not signal a letter. You switch between them in Settings or from the menu bar, and each mode remembers its own outputs.

What can the keyboard lights tell me?

A letter or a whole number (counted blinks), yes or no (one or two long lights), that an answer is ready to read in the window (two short blinks), or that something went wrong (three quick blinks). Longer answers are not spelled out in light; you read those in the window.

Which AI does it use?

Google's Gemini models, through an API key you create in Google AI Studio and paste into Settings. You can pick the model there. ScreenPulse needs an internet connection to answer. Like any AI, it can be wrong, so check answers that matter.

What happens to my screen content?

Nothing is captured until you press the shortcut. Then one image of the display under your pointer is sent from your Mac directly to Google's Gemini API, and the temporary file is deleted. ScreenPulse has no servers of its own and no analytics. Your API key is stored in the macOS Keychain. Everything visible on that display is part of the image, so keep private material off screen when you ask, and see Google's terms for how the Gemini API handles data.

Is the answer window hidden from screen sharing?

No. It is an ordinary window and shows up in screen sharing and recordings like any other. You can choose not to show it at all, which is a setting for a calmer workspace, not a way around monitoring.

Can I use ScreenPulse in an exam or a test?

No. ScreenPulse is not made for exams, graded tests, certifications, or any setting where AI help is not allowed. Use it for your own work and learning, and follow the rules that apply where you are.

How do I get a Gemini API key?

It takes a few minutes and needs only a Google account. The setup guide on this site walks you through it step by step with pictures, and the app has a Check key button that tells you if the key works.

How do I install it?

Download ScreenPulse.dmg, open it and drag ScreenPulse onto Applications. Then open the app, paste your Gemini API key in Settings, and allow Screen Recording (to capture the screen) and Input Monitoring (to control the Caps Lock light) in System Settings. macOS asks you to confirm Screen Recording again from time to time.

Is ScreenPulse free?

Yes. ScreenPulse is free and open source under the Apache License 2.0. You only pay Google for the Gemini usage on your own key, and only if your key has billing turned on. The name and logo are not covered by the licence.

What about updates and support?

ScreenPulse is a spare-time project. New versions are published on GitHub, and the app can tell you when one is out (it asks first, and you can turn it off). You download the new disk image and drag ScreenPulse onto Applications again. Support is community support through GitHub Issues, with no promised response time. A report from the `capsled probe` command on your MacBook helps a lot.

About ScreenPulse

ScreenPulse began with a small observation: a laptop has more ways to tell you something than its screen.

AI assistants have mostly settled on one shape, a text box that fills up with paragraphs. That is right for some moments and too much for others. Sometimes you want the full explanation in front of you. Sometimes you want one fact without moving a window.

We build ScreenPulse around that choice. The software reads what you point at, the AI works out the answer, and you decide how much of it you want and where it lands: a window, the lights on your keyboard, or both. We want to keep finding new, quieter ways for people and AI to talk to each other, and to be plain about what works on which Mac.
