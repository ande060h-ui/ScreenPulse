Get it

Privacy

ScreenPulse does not collect data about you. This page says what happens to the data that does move.

In short

  • There are no accounts, no telemetry, no analytics and no ScreenPulse servers.
  • Nothing is captured until you press the shortcut.
  • When you do, one image of your screen goes from your Mac straight to Google, using your own API key.
  • Your key and settings stay on your Mac.
  • An optional update check asks GitHub, once a day, whether a new version exists, and only if you allow it.

The app

When you press the shortcut, ScreenPulse captures the display your pointer is on, including the pointer, and sends that one image together with your question to Google's Gemini API. Everything visible on that display is part of the image, so close or move anything you do not want sent, and only use ScreenPulse on content you may share. The temporary image file on your Mac is deleted after the request.

Your API key is stored in the macOS Keychain. Your settings are stored in your Mac's user preferences. Optional background notes that you put in the Knowledge folder stay on your Mac and are sent to Google as part of your questions. The project receives none of this.

What Google does with it

Google, not this project, decides how it handles what it receives, under the terms that apply to your key. Those terms can differ between free keys and keys with billing turned on: on free keys Google may use content to improve its products, and people at Google may read it. Check Google's current terms before using ScreenPulse with private content. The setup guide explains why we recommend a key with billing and a spending limit.

This website

The website is a static site. It sets no cookies, runs no analytics and loads its fonts from itself. It is hosted by Vercel, which, as with any website, sees technical request data such as your IP address. See Vercel's privacy policy.

Update check

The first time you start ScreenPulse, it asks whether it may look for new versions. If you agree, it sends one request to GitHub's public release address for this project, at most once a day. GitHub then sees your IP address and the name and version of the app (as the User-Agent), nothing else. ScreenPulse never downloads or installs anything by itself: it only offers to open the release page. You can switch the check off in Settings, and you can run it yourself with Check for Updates… in the menu.

GitHub

The source code and issue tracker are on GitHub. What you post there, such as an issue or a pull request, is public and handled under GitHub's terms. Never post your API key or private screenshots.

If this changes

If the project ever adds accounts, a server or telemetry, this page will be updated first, and the app will say so.
